# Adetunji Tomiwa Shoaga — Portfolio

Personal portfolio for **Adetunji Tomiwa Shoaga**, a Computer Science undergraduate at Olabisi Onabanjo University building toward backend and systems engineering in **Go** and **PostgreSQL**, backed by a practical foundation in **React** and modern frontend development.

## Overview

Built with React and Vite on a paper-tone visual system (`#f3f2ed` ground, `#e8e7df` surface, `#fffefa` card highlights, `#c7f36a` lime accent, and `#191a17` ink), the site presents:

- **Hero & Floating Dock (`Hero`, `Nav`):** Direct introduction, top floating navigation dock (`Home`, `About`, `Work`, `Stack`, `Contact`), and `IntersectionObserver` active-section tracking.
- **About & Positioning (`Context`):** Background as a Computer Science student preparing for industrial training and backend systems work.
- **Selected Work (`Work`):** Scrollable project track with arrow and dot navigation showcasing **ScamCheck** (frontend UI and API integration) and **Avid Store** (React storefront built against the Fake Store API).
- **Stack (`Stack`):** Card grid separating active frontend tools (**React**, **JavaScript**, **Tailwind CSS**, **HTML/CSS**, **Git/GitHub**) from areas actively expanding (**Go**, **PostgreSQL**, **SQL**, **TypeScript**, **Linux**, **Docker**).
- **Contact (`Contact`):** Direct contact details for internships, SIWES placements, and engineering collaborations.

## Stack

- **Frontend Baseline:** React, JavaScript, HTML5, CSS3, Tailwind CSS, Vite
- **Backend & Systems Direction:** Go (Golang), PostgreSQL, SQL, TypeScript, Linux, Docker
- **Tooling:** Git, GitHub
