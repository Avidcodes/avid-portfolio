
# Personal Developer Portfolio

Welcome to the repository for my personal developer portfolio! This project showcases my work, technical foundation, and active trajectory as a Computer Science student advancing into full-stack and systems engineering.

Built with a custom design system featuring warm paper tones (`#f3f2ed`), dynamic micro-interactions, responsive CSS keyframes, and a modular React component architecture.

---

## ✨ Standout Features

- **Interactive Bottom Navigation Dock**: A custom frosted-glass floating dock bar that tracks scroll position, highlights active sections dynamically, and features smooth hover tooltips.
- **Infinite Brand Marquee**: A dynamic tech stack showcase featuring vector brand SVGs with continuous CSS scrolling, automatic pause-on-hover, and sleek tooltips.
- **Interactive Project Carousel**: Touch/drag-friendly project showcase displaying real-world web applications and projects with live demo/repo links.
- **Tailored Aesthetics**: Lightweight, custom design tokens leveraging a minimalist paper-texture theme, CSS variables, and seamless micro-animations.
- **Mobile-First Responsiveness**: Designed from the ground up to render cleanly across all viewport sizes, from mobile phones to high-resolution desktop screens.

---

## 🛠️ Technical Stack

### Frontend & Core

- **Library**: React 18+ (Vite)
- **Styling**: Modern CSS3 (Variables, Keyframe Animations, Mask-Image, CSS Grid/Flexbox) & Tailwind CSS
- **Forms & Validation**: React Hook Form, Zod
- **Icons & Media**: Devicon SVG CDN, Lucide / Feather Icons

### Expanding Into (Target Stack)

- **Languages**: TypeScript, C#
- **Frameworks & Backend**: Next.js, ASP.NET Core
- **Database & DevOps**: PostgreSQL, Docker, Git/GitHub

## ⚡ Quick Start

Follow these steps to run the portfolio locally on your machine.

### 1. Clone the repository

```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
```

### 2. Install project dependencies

```bash
npm install
```

### 3. Launch the local Vite development server

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173`.

### 4. Create a production build

```bash
npm run build
```

## 🎨 Theme & Design Tokens

Global design tokens configured inside `index.css`:

```css
:root {
  --paper: #f3f2ed;         /* Primary canvas background */
  --paper-deep: #e8e7df;    /* Container & card background fills */
  --ink: #191a17;           /* High-contrast typography & elements */
  --muted: #6c6e65;         /* Secondary body & caption text */
  --accent: #c7f36a;        /* High-energy lime highlight */
  --accent-dark: #9bc642;   /* Deep accent border/dot indicator */
  --white: #fffefa;         /* Highlight card fill */
  --ease: cubic-bezier(0.16, 1, 0.3, 1);
}
```
